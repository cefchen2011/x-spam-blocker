# X 垃圾帖屏蔽 v1.1.1

修掉两个让「屏蔽」按钮不出现的 bug。

## 修复

### 搜索结果页整页没有按钮

转换器原先只识别首页那种时间线结构，搜索页用的是另一种，于是**搜索结果里的帖子全部被跳过**。
现在改成递归遍历整份响应中的所有 `instructions`，首页、搜索、话题串、个人页等结构都能覆盖。

### 带 emoji 的帖子按钮变成裸链接

注入后有的帖子显示蓝色「屏蔽」，有的却把 `https://t.co/XSB...` 原样打印出来。
原因是 **X 用 Unicode 码点计算实体下标，而 Java 字符串是 UTF-16**——帖子里每有一个 emoji
（占两个 UTF-16 单元），下标就整体偏移，X 判定实体越界后直接丢弃。已在写入前换算成码点下标。

### 另外确认

`expanded_url` 必须是 https。指向本地 Web 服务的 `http://127.0.0.1:...` 会让 X 丢掉整个实体，
所以控制项统一用 https 标记地址 + Intent 拦截完成点击；本地服务保留为兜底通路。

## 安装

1. 安装本 APK。
2. LSPosed 中启用「X 垃圾帖屏蔽」，作用域勾选 **X**，强行停止 X 后重新打开。
3. 打开一次模块 App 确认「运行状态」为**已连接**；需要 AI 判定就在「AI 判定」里填入自己的 DeepSeek API Key 并「保存并测试」。

仓库与 APK 内不含任何密钥。详细原理与实机证据见
[docs/verification.md](https://github.com/cefchen2011/x-spam-blocker/blob/main/docs/verification.md)。
