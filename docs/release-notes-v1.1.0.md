# X 垃圾帖屏蔽 v1.1.0

## 本次更新

### 判定逻辑简化为两级

```
if (回复里带有 @) {
    if (本地规则命中)      显示屏蔽;   // 立即，不等网络
    else if (AI 判为垃圾)  显示屏蔽;
}
```

- 候选范围从 `@某人,` 放宽到**任意带 `@` 的回复**，不再漏掉形状不同的揽客回复
- 提示词同步放宽：不再要求以 `@` 开头，只要是性暗示揽客都算；对色情内容的批评/讨论不算
- 原先的「严格模式」开关随之取消（新逻辑里 AI 分支本来就只在判为垃圾时才显示）
- 每批时间线响应最多排 8 条 AI 调用，跑在 2 线程池上，不阻塞时间线

### 关键词管理

- 点任意关键词芯片 → 确认框 → **删除**该关键词，该账号的帖子重新出现
- **清空全部** 按钮 → 一次删除所有关键词
- 删除请求经广播交给 X 进程执行，执行后新列表回传，界面即时刷新

### 其它

- 仓库与 APK 内不含任何密钥；API Key 在设置页填写（未填时 AI 判定保持关闭，退回纯本地规则）
- 构建脚本不再依赖本机路径，自动从 `JAVA_HOME` / `ANDROID_SDK_ROOT` 推导工具链

## 安装

1. 安装本 APK。
2. LSPosed 中启用「X 垃圾帖屏蔽」，作用域勾选 **X**，强行停止 X 后重新打开。
3. 打开一次模块 App 确认「运行状态」为**已连接**；需要 AI 判定就在「AI 判定」里填入自己的 DeepSeek API Key 并点「保存并测试」。

## 说明

- X 服务端的「已静音的字词」同步需要与单次请求绑定的设备证明签名，重放请求会被 400 拒绝，
  因此屏蔽由模块在本地执行。
- 帖子被自动翻译时译文会顶掉注入的链接，点「显示原文」即可看到可点击的按钮。

原理、实机证据与踩坑记录见 [docs/verification.md](https://github.com/cefchen2011/x-spam-blocker/blob/main/docs/verification.md)。
