# X 垃圾帖屏蔽 v1.0.0

面向 Android 原生 X（Twitter）客户端的 LSPosed 模块：识别 `@某人,内容` 形式的性暗示垃圾回复，
在帖子末尾加一个可点击的 **屏蔽** 按钮，点一下就把该账号加入屏蔽关键词，其帖子立即从时间线消失。

在 **X 12.25.0-prod.01 / Android 16 / LSPosed v2.1.1** 上实机验证。

## 功能

- **检测**：正则筛出 `@handle,` / `@handle，` 形状，配合约 100 个中英文性暗示词库
- **屏蔽按钮**：帖子末尾出现蓝色「屏蔽」，点击即生效
- **生效**：关键词落到 X 数据目录，匹配的帖子从时间线的 `entries` 中移除
- **双点击通路**：X 进程内的 `127.0.0.1` HTTP 服务（真实可达链接）+ Activity Intent 拦截（无感，不弹浏览器）
- **AI 判定**：规则筛候选 → `deepseek-flash` 判定；结论按正文 MD5 缓存、异步调用、不阻塞时间线
- **Material 3 设置页**：运行状态、屏蔽词 Chips、测试模式、AI 配置（含「保存并测试」），跟随系统浅色/深色

## 安装

1. 安装本 APK。
2. LSPosed 中启用「X 垃圾帖屏蔽」，作用域勾选 **X**。
3. 强行停止 X，再重新打开。
4. 打开一次模块 App 确认「运行状态」为**已连接**；需要 AI 判定就在「AI 判定」里填入自己的 DeepSeek API Key。

## 说明

- **仓库与 APK 内不含任何密钥。** 不填 Key 时 AI 判定保持关闭，模块退回纯本地规则。
- 开启 AI 判定后，被判为候选的回复正文会发送到 DeepSeek 接口。
- X 服务端的「已静音的字词」同步需要与单次请求绑定的设备证明签名，重放请求会被 400 拒绝，
  因此屏蔽由模块在本地执行；相关重放代码保留并在日志中报告结果。
- 帖子被自动翻译时译文会顶掉注入的链接，点「显示原文」即可看到可点击的按钮。

详细原理、实机证据与踩坑记录见 [docs/verification.md](https://github.com/cefchen2011/x-spam-blocker/blob/main/docs/verification.md)。
